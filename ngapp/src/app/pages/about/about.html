Full Stack Web Development

Building modern web applications with Angular and Next.js.

Project Overview

This project explores the development of modern web applications using Angular and Next.js. It demonstrates how frontend frameworks interact with REST APIs to retrieve and display dynamic data.

The application includes product browsing, pagination, product details, navigation between pages, and form validation.

Technologies Used

🌐
